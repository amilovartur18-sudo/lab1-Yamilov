# 2

1) Калькулятор:

- Работает с целыми и дробными числами.
- Поддерживает операции `+`, `-`, `*`, `/`.
- Учитывает порядок действий: `*` и `/` считаются раньше `+` и `-`.
- Поддерживает знак перед числом: `-5`, `+7`, `2 * -3`.
- Пробелы между числами и знаками не влияют на результат.

2) Конвертер переводит:

- Длину: `mm`, `cm`, `m`, `km`.
- Массу: `g`, `kg`.
- Температуру: `c`, `f`, `k`.

Регистр единиц не важен: можно писать `kg`, `KG` или `Kg`.
Перевод между разными группами запрещён. Например, килограммы в метры перевести нельзя.
Температура ниже абсолютного нуля запрещена.

# 3 Установка

В настройках проекта указано требование Python 3.12 или новее.

Скачать репозиторий:

```bash
git clone https://github.com/amilovartur18-sudo/lab1-Yamilov.git
cd lab1-Yamilov
```

Поставить зависимости и программу:

```bash
uv sync
```

# 4 Запуск

Справка:

```bash
uv run python -m toolkit --help
```

Вычисление выражения:

```bash
uv run python -m toolkit calc "2+3*4"
```

Результат: `14.0`.

Выражение со знаком минус:

```bash
uv run python -m toolkit calc "2*-3"
```

Результат: `-6.0`.

Выражение с пробелами нужно брать в кавычки:

```bash
uv run python -m toolkit calc "2 * -3"
```

Результат: `-6.0`.

Перевод миллиметров в метры:

```bash
uv run python -m toolkit convert 1000 --from mm --to m
```

Результат: `1.0`.

Перевод градусов Цельсия в градусы Фаренгейта:

```bash
uv run python -m toolkit convert 0 --from c --to f
```

Результат: `32.0`.

# 5 Как работает калькулятор

Вычисление состоит из трёх шагов:

1. `tokenize` делит строку на числа и знаки. Пробелы пропускаются. Минус или плюс перед числом становится частью этого числа, если он стоит в начале или сразу после другого знака. Поэтому `2*-3` превращается в список `[2.0, "*", -3.0]`.
2. `validate` проверяет, что дальше идёт число, знак, число, знак и так далее.
3. `calculate` считает в два прохода. Сначала выполняются `*` и `/`. Потом `+` и `-` слева направо. Для `2+3*4` после первого прохода остаётся `[2.0, "+", 12.0]`, затем `2 + 12` даёт `14.0`.

Скобки программа не поддерживает.

# 6 Правила для чисел и операций

Дробная часть записывается через точку: `12` и `1.5` допустимы.
Запись `1e3` и запятая в числе не поддерживаются.

Умножение нужно писать явно: `2*3`.
Деление `/` даёт дробный результат: `10/4` равно `2.5`.

Длина переводится через метры, масса через граммы, температура через кельвины.
`0 °C` равен `32 °F` и `273.15 K`. Абсолютный ноль равен `0 K`, `-273.15 °C` и `-459.67 °F`.

# 7 Ошибки и ограничения

Программа сообщает об ошибке, если:

- выражение пустое;
- в выражении есть недопустимый символ, например `2+a`;
- число записано неверно;
- пропущено число или знак;
- два знака операций стоят подряд, например `2*/3`;
- выражение обрывается на знаке, например `2+`;
- происходит деление на ноль;
- указана неизвестная единица измерения;
- единицы принадлежат разным группам, например `kg` и `m`;
- температура ниже абсолютного нуля, например `-300 °C`.

Сообщение об ошибке выводится в `stderr` и начинается с `Error:`.
Коды завершения:

- `0` — успешное выполнение;
- `2` — ошибка пользователя.
