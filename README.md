# Лабораторная работа 1 — toolkit

Консольный набор утилит: калькулятор арифметических выражений и конвертер величин.

## Запуск

```bash
uv sync
uv run python -m toolkit --help
uv run python -m toolkit calc "2+3*4"
uv run python -m toolkit convert 1000 --from mm --to m
```

## Калькулятор

Разбор выражения в три шага:

1. **tokenize** — строка → числа и операторы (унарный `+/-` «прилипает» к числу);
2. **validate** — проверка корректности последовательности токенов;
3. **calculate** — два прохода: сначала `*` и `/`, потом `+` и `-`.

Пример для защиты: `2*-3` → токены `[2, '*', -3]` → `-6`.

## Конвертер

- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`

Регистр единиц не важен. Конвертация между разными группами запрещена.
Температура ниже абсолютного нуля запрещена.
